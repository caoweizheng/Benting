# 本汀移动端项目说明文档

## 项目概述

**项目名称**: 本汀移动端 (Benting Mobile)  
**项目类型**: React + Next.js 移动端Web应用  
**主要功能**: 综合性移动端平台，包含社交、电商、娱乐等多种功能  

本项目是一个基于Next.js框架开发的移动端Web应用，主要服务于本汀平台的移动端用户，提供丰富的社交互动、商品购买、活动参与等功能。

## 技术架构

### 核心技术栈
- **前端框架**: React 16.3.2 + Next.js 5.1.0
- **状态管理**: MobX 3.3.3 + MobX-React 4.3.5
- **UI组件库**: Ant Design Mobile 2.1.2
- **服务端**: Express 4.16.2
- **构建工具**: Next.js内置Webpack
- **样式处理**: CSS Modules + 内联样式

## 主要功能模块

### 1. 首页模块 (`/`)
- **轮播图**: 展示活动和推广内容
- **功能菜单**: 快速导航到各个功能模块
- **活动信息**: 显示当前进行的活动
- **鱼获有礼**: 特色功能模块
- **明星推荐**: 明星相关内容展示
- **视频内容**: 置顶视频展示
- **资讯信息**: 最新资讯列表

### 2. 论坛模块 (`/bbs`)
- **版块浏览**: 不同主题的讨论版块
- **文章发布**: 用户可发布帖子和文章
- **互动功能**: 点赞、评论、收藏
- **用户注册**: 论坛用户注册功能

### 3. 商城模块 (`/shop`)
- **商品展示**: 商品列表和详情页
- **购物功能**: 加购物车、下单购买
- **拍卖功能**: 商品拍卖和竞价
- **秒杀活动**: 限时秒杀商品
- **优惠券**: 优惠券领取和使用

### 4. 个人中心 (`/person`)
- **用户信息**: 个人资料管理
- **订单管理**: 查看和管理订单
- **钱包功能**: 余额和交易记录
- **地址管理**: 收货地址管理
- **银行卡**: 银行卡绑定管理
- **积分系统**: 积分查看和兑换
- **等级系统**: 用户等级和权益

### 5. 商户模块 (`/merchant`)
- **商户入驻**: 商户注册和认证
- **商户详情**: 商户信息展示
- **会员管理**: 商户会员系统
- **抽奖活动**: 商户抽奖功能
- **二维码**: 商户二维码生成

### 6. 视频模块 (`/video`)
- **视频列表**: 视频内容浏览
- **视频详情**: 视频播放和互动
- **视频上传**: 用户上传视频内容

### 7. 明星模块 (`/star`)
- **明星列表**: 明星信息展示
- **明星详情**: 明星详细信息和动态

### 8. 活动模块 (`/event`)
- **签到活动**: 每日签到功能
- **楼层活动**: 楼层相关活动
- **竞猜活动**: 竞猜游戏
- **红包活动**: 红包发放和领取

### 9. 认证模块 (`/auth`)
- **用户登录**: 多种登录方式
- **用户注册**: 新用户注册
- **抽奖认证**: 抽奖相关认证

## 开发环境配置

### 环境要求
- Node.js >= 8.0
- npm 或 yarn 包管理器

### 安装步骤
1. 克隆项目到本地
2. 进入项目目录：`cd dev.tw-bt.com.mobile`
3. 安装依赖：`npm install` 或 `yarn install`

## 运行指南

### 开发模式
```bash
npm run dev
```
启动开发服务器，默认运行在 http://localhost:3000

### 生产构建
```bash
npm run build
```

### 生产运行
```bash
npm run start
```
运行生产版本

## 开发规范

### 目录命名规则
- 页面组件放在 `pages/` 目录下
- 可复用组件放在 `src/` 对应模块目录下
- 公共组件放在 `src/_/` 目录下
- 状态管理文件放在 `stores/` 目录下

### 组件命名规范
- 页面组件使用 PascalCase
- 私有组件以下划线开头：`_ComponentName`
- 文件名与组件名保持一致

### 状态管理
- 使用 MobX 进行状态管理
- 全局状态放在 `stores/g.js`
- UI状态放在 `stores/ui.js`
- 页面级状态放在对应的 `store.js` 文件中

## 部署说明

项目支持服务端渲染(SSR)，可以部署到支持Node.js的服务器环境中。

### 部署步骤
1. 执行 `npm run build` 构建项目
2. 将构建后的文件上传到服务器
3. 在服务器上执行 `npm run start` 启动应用

## 注意事项

1. 项目使用了微信相关功能，需要在微信环境中测试
2. 部分功能依赖于第三方服务（如高德地图）
3. 图片资源使用了CDN加速
4. 项目包含支付功能，需要相应的支付接口配置
